# 学マス サポートカード比較

学園アイドルマスターのサポートカードによるステータス上昇量を比較する非公式Webアプリケーションです。

## 機能

- **比較**：カード名・スキルカード名／Pアイテム名の検索、複数条件での絞り込み、名前・最大点等の並び替え。一律0～4凸と所持凸数での比較。
- **所持状況**：未所持・0～4凸の登録、一括変更、直前1操作のUndo、JSONのエクスポートとインポート。
- **編成**：最大6枚の配置、ドラッグ・タップ、枠ごとの凸数、プラン別の12テンプレート、個別最大点の合計とSP発生率補正。
- **詳細**：効果、サポートイベント、タイプ別点数、計算式、日程と発動回数の根拠。
- **育成条件**：SP回数・日別指定、試験配分、行動回数、相談等の操作数。比較・編成・詳細で共有。
- **その他**：使い方ガイド、サイト概要、要望・不具合の連絡先、免責事項、保存とアクセス解析の説明。
